### 2.3 标题样式设置

```typescript
interface HeadingStyleConfig {
  font: {
    fontFamily: string       // 默认 "SimSun"（宋体）
    fontSize: string        // 默认值随级别变化
    color: string           // 默认 "#000000"
    bold: boolean           // 是否加粗，默认值随级别变化
  }

  alignment: "left" | "center" | "right" | "justify"  // 左对齐/居中/右对齐/两端对齐

  spacing: {
    spaceBeforeLines: number   // 段前间距（行）
    spaceAfterLines: number    // 段后间距（行）
  }

  indent: {
    leftChars: number      // 左缩进（字），默认 0.00
    firstLineChars: number  // 首行缩进（字），默认 0.00
  }

  outlineLevel: number  // 大纲级别，对应 2–6

  lineSpacing: {
    multiple: number   // 多倍行距，1.0表示单倍行距，默认 1.0
  }
}
```

| 3级 | SimSun（宋体） | 四号 | 是 | 0.67行 | 0.67行 | 3 | 1.0 |
| 4级 | SimSun（宋体） | 小四 | 否 | 0.50行 | 0.50行 | 4 | 1.0 |
| 5级 | SimSun（宋体） | 11 | 否 | 0.33行 | 0.33行 | 5 | 1.0 |
| 6级 | SimSun（宋体） | 10 | 是 | 0.33行 | 0.33行 | 6 | 1.0 |
