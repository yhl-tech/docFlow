# 编辑器模板配置增强方案

## 一、需求分析

### 1.1 缺失功能清单

根据截图对比现有系统，以下功能需要新增：

#### 纸张设置（新增）

| 功能         | 说明                           |
| ------------ | ------------------------------ |
| **纸张方向** | 横向/纵向切换                  |
| **纸张大小** | A4、B5、16K、Letter、Folio、8K |

#### 字体样式配置

| 功能         | 说明                                 |
| ------------ | ------------------------------------ |
| **字体颜色** | 样式槽位需要颜色选择器（类型已有）   |
| **斜体**     | 样式槽位需要斜体切换按钮（类型已有） |

#### 列表样式配置（新增）

| 功能             | 说明                                                           |
| ---------------- | -------------------------------------------------------------- |
| **无序列表样式** | 字符（● ■ ▼ ☐ ☑）、颜色、字体、字号                            |
| **有序列表样式** | 编号格式、对齐方式、编号后自动生成、继续编号、颜色、字体、字号 |

#### 图片样式设置（新增）

| 功能           | 说明                                  |
| -------------- | ------------------------------------- |
| **位置与环绕** | 水平位置、环绕方式、锁定选项          |
| **文字环绕**   | 环绕文字于、距正文距离                |
| **图片样式**   | 裁剪区域、效果、亮度/对比度、重新着色 |

#### 代码块样式设置（新增）

| 功能           | 说明                                     |
| -------------- | ---------------------------------------- |
| **边框和底纹** | 预设、颜色、宽度、各边框开关、底纹填充色 |
| **快捷键样式** | 前景色、背景色                           |
| **行号**       | 显示开关、颜色                           |
| **制表位**     | 默认制表位、缩进方式                     |

#### 表格样式设置（新增）

| 功能           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **边框和底纹** | 预设、颜色、宽度、边框样式、各边框开关                       |
| **底纹**       | 填充色、颜色                                                 |
| **选项**       | 指定格式和网格、使用主题格式、标题行重复、允许拆分表格、对齐 |
| **字体和章节** | 字体、字号、颜色                                             |

#### 页码样式设置（新增）

| 功能         | 说明                                      |
| ------------ | ----------------------------------------- |
| **基础设置** | 启用页码、位置、对齐                      |
| **页码格式** | 阿拉伯数字、小写罗马、大写罗马            |
| **格式设置** | 起始值、续前节、首页显示页码、章节设置    |
| **标签模板** | 第{ N }页、共{ N }页、Page { N } of { P } |
| **字体样式** | 字体、字号、颜色                          |

#### 页面布局配置

| 功能         | 说明                                     |
| ------------ | ---------------------------------------- |
| **页眉页脚** | 首页不同、奇偶页不同、分栏布局（仅文字） |

### 1.2 现有功能（已实现）

- 字体选择、字号选择、加粗、对齐方式
- 页边距、行间距、段间距、首行缩进

### 2.7 表格样式设置

```typescript
interface TableStyleConfig {
  // 边框和底纹
  border: {
    preset: "none" | "all" | "grid" | "outline" | "inside" // 预设
    color: string // 边框颜色
    widthPt: number // 宽度（磅）
    style: "single" | "double" | "dashed" | "dotted" // 边框样式
    // 各边框开关
    leftBorder: boolean
    rightBorder: boolean
    topBorder: boolean
    bottomBorder: boolean
    insideHorizontalBorder: boolean
    insideVerticalBorder: boolean
  }

  shading: {
    fill: string // 填充色
    color: string // 颜色
    applyTo: "paragraph" | "cell" | "table" // 应用于
  }

  // 选项
  options: {
    specifyFormat: boolean // 指定格式和网格
    useThemeFormat: boolean // 使用主题格式
    repeatHeaderRow: boolean // 标题行重复
    allowSplitTable: boolean // 允许在单元格中拆分表格
    useAlignment: boolean // 对边框和底纹使用对齐
  }

  // 字体和章节
  font: {
    fontFamily: string // 字体
    fontSizePt: number // 字号
    color: string // 颜色
  }
}
```
